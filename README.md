# Core Daily

Personalised daily core workouts as an installable web app (PWA).

- Configure duration (9/12/15/18 min), intensity, target area, equipment and movement complexity
- Generator builds the session from a library of 50+ exercises
- Interval timer: Low 30/30 · Medium 40/20 · High 50/10, with 1 min warm-up and a cool-down stretch
- Animated exercise figures, beeps, vibration and voice coach
- Works offline once installed

Install on Android: open the GitHub Pages URL in Chrome → menu ⋮ → "Add to Home screen" / "Install app".
